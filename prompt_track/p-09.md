# 09 · Guardrails — by prompt

The goal: have the agent wrap your agent in safety checks, then review them the way you'd review
an IAM policy or a WAF rule — because that's mostly what they are, plus one new thing.

## Drive

> Add guardrails to an agent in `guardrails.py` (anthropic SDK) so it fails safe. Include:
> - Input validation (reject empty or oversized input before any model call).
> - A tool allow-list: even if the model requests a tool, refuse anything not explicitly
>   allowed.
> - A max-iterations cap and a cumulative cost ceiling that aborts the run.
> - Output validation (reject empty final output).
> Then demonstrate each guardrail tripping: a normal run, oversized input, empty input, and a
> prompt-injection attempt that tries to get the agent to call a forbidden tool.

Good output runs the normal case and shows each bad case being blocked with a clear reason.

## Review

- **Does the allow-list actually refuse unlisted tools?** This is your real defense against
  prompt injection. You can't stop text from *trying* to hijack the model; you make sure the
  dangerous tool simply isn't callable. Test the injection case yourself and confirm it's blocked
  at the tool layer, not just by the model declining.
- **Are user input and tool results treated as untrusted?** Either can carry an injection.
  Neither should be able to silently change the rules.
- **Is there still a cost ceiling and an iteration cap?** Same discipline as every loop lesson.
- **Map each guardrail to what you already run:** allow-list → IAM, ceiling → budget alert,
  max-iter → timeout, input validation → WAF. If one of yours has no equivalent, ask whether it's
  actually needed.

Push back:

> The prompt-injection case is only blocked because the model chose not to comply. Enforce it at
> the tool layer with the allow-list so a forbidden tool can never run even if the model is fooled.

## Understand

Most of this is your existing ops skills aimed at an LLM; prompt injection is the new part, and
the allow-list is the durable defense. Deep dive: [09 · Guardrails](../pages/ops-09.html).
