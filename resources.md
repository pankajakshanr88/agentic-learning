# Resources — the canon

Curated, not exhaustive. Read the starred (★) ones this weekend; the rest are for the
CAREER.md phase.

## Read first (this weekend)
- ★ **Building Effective Agents** — Anthropic. The single best framing of workflows vs.
  agents and the core patterns. https://www.anthropic.com/research/building-effective-agents
- ★ **Anthropic Tool Use docs** — how function calling actually works.
  https://docs.anthropic.com/en/docs/build-with-claude/tool-use
- ★ **A Visual Guide to LLM Agents** — quick intuition for the loop.

## Foundations (LLM mechanics)
- **Anthropic — Build with Claude** docs (messages, streaming, models, pricing).
  https://docs.anthropic.com/
- **Andrej Karpathy — "Intro to LLMs" (1hr talk)** — the best single explainer of what's
  inside the box.
- **Prompt engineering guide** — https://docs.anthropic.com/en/docs/build-with-claude/prompt-engineering

## Agent patterns & frameworks
- **Claude Agent SDK** — https://docs.anthropic.com/ (search "Agent SDK").
- **LangGraph** — graph-based agent orchestration; common in job postings.
  https://langchain-ai.github.io/langgraph/
- **ReAct paper** — "ReAct: Synergizing Reasoning and Acting in LLMs" (Yao et al.).
- **Reflexion paper** — self-reflection/critique loops.

## MCP (Model Context Protocol)
- **MCP spec + docs** — https://modelcontextprotocol.io/ . As a DevOps person, the
  *server/hosting* side of MCP is a natural specialty for you.

## Production / LLMOps (your edge — start here for the pivot)
- **Evaluating LLM apps / "evals"** — Anthropic + OpenAI eval cookbooks.
- **Observability for LLMs** — LangSmith, Langfuse, Arize Phoenix (tracing/eval platforms).
- **Prompt injection & agent security** — OWASP "Top 10 for LLM Applications".
- **Chip Huyen — "AI Engineering" (book)** — the best survey of the production stack.

## Practice
- **Anthropic Cookbook** (GitHub) — runnable recipes for tools, RAG, agents.
- Build, don't just read. The capstone here is your first portfolio piece.
